O que é Acessibilidade Web?

A acessibilidade web refere-se à prática de tornar os websites utilizáveis por pessoas com deficiência.

De acordo com as Diretrizes de Acessibilidade para Conteúdo Web (WCAG), o contraste mínimo para texto normal deve ser de 4.5:1 (Nível AA). Para o nível AAA, o contraste mínimo é de 7:1.

Requisitos de Espaçamento

Para atender aos requisitos de acessibilidade de espaçamento (WCAG 2.1, 1.4.12 Text Spacing), o texto deve poder ser ajustado para:

  • Altura da linha (espaçamento entre linhas) de pelo menos 1,5 vezes o tamanho da fonte.
  • Espaçamento dos parágrafos seguintes de pelo menos 2 vezes o tamanho da fonte.

O redimensionamento de texto deve permitir que o usuário aumente o tamanho da fonte em até 200% sem perda de conteúdo ou funcionalidade.
