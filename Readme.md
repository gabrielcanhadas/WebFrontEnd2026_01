## ✅ Procedimentos de Avaliação

## 🛠️ Desenvolvimento do PROJETO

O Projeto Prático da disciplina **Programação Web Front-end** consiste no desenvolvimento de uma aplicação web, utilizando os conhecimentos abordados ao longo do semestre.

O projeto será desenvolvido em **equipes de até 3 integrantes** e será avaliado em duas etapas:

### 🔹 Etapas do Projeto

#### 1️⃣ Projeto – HTML e CSS
Consiste na elaboração de um website utilizando **HTML e CSS**, focando na construção do layout e estrutura das páginas.

O projeto deve conter, no mínimo:

- 1 página principal (solução proposta)
- 1 página de cadastro, contendo:
  - pelo menos 5 campos de formulário
  - botão de envio direcionando para página de login
- Código HTML e CSS **validados** nos validadores oficiais:
  - https://validator.w3.org/
  - https://jigsaw.w3.org/css-validator/

Na **página principal**, devem estar presentes:
- Cabeçalho e rodapé
- Menu de navegação
- 2 ou mais ícones
- 3 ou mais caixas de texto (p, span, li, etc.)
- 3 ou mais imagens
- 3 ou mais links
- 3 ou mais cores
- 2 ou mais fontes

#### 2️⃣ Projeto – JavaScript
Continuação do projeto com a implementação de funcionalidades utilizando **JavaScript**, aplicando os conceitos vistos em sala de aula.

---

### 🎯 Objetivos do Projeto

- Aplicar na prática os conceitos estudados
- Simular um ambiente real de desenvolvimento web
- Desenvolver soluções para problemas reais

---

### 🌍 Tema do Projeto

O projeto deve propor um serviço que:
- atenda a um **Objetivo de Desenvolvimento Sustentável (ODS)**  
  **ou**
- resolva um problema de uma comunidade local

#### Exemplos:
- Página web de uma ONG local
- Página web de um pequeno comércio
- Serviço gratuito de ensino remoto
- Plataforma de apoio à inserção de mulheres na área de TI

---

### ✅ Critérios de Avaliação

1. Utilização adequada dos conceitos estudados em sala de aula
2. Sincronização do projeto com repositório no **GitHub**, mantendo:
   - sequência cronológica de commits
   - evolução contínua ao longo do semestre
3. Apresentação do projeto finalizado

#### Atribuição de notas para os itens do projeto

1. (2,5) Implementação da página principal em HTML e CSS semântico
2. (2,5) Implementação da página de cadastro em HTML e CSS semântico
3. (1,5) Publicação no GitHub Pages
4. (1,5) Repositório GitHub bem documentado:
   - README completo
   - commits organizados e cronológicos
5. (1,0) Inclusão de currículo dos integrantes no rodapé
6. (1,0) Qualidade do vídeo de apresentação
